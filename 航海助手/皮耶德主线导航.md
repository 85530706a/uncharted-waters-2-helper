# 皮耶德·康迪主线攻略

适用于桌面《大航海时代 II》DOS 中文版。主线看**冒险名声**。可在修改器把冒险声望设为 50,000，可以按顺序做剧情，不用特意刷名声。皮耶德找的是传说中的黄金国埃尔多拉多。

## 1. 热那亚出发，去里斯本找资助人

1. 在出生港**热那亚（Genoa）**，先去**酒馆**找朋友**凯麦隆**。他说里斯本的法雷尔公爵夫人愿意资助你的冒险，也愿意替你还债。
2. 听完去**热那亚码头**，与凯麦隆会合，拿到船「法尔孔」。从这里出海去**里斯本（Lisbon）**。
3. 到里斯本，进**法雷尔公爵宅**找公爵夫人。谈妥资助后，再去**码头**把出发前的对白听完。
4. 发现物继续向**法雷尔家**报告。和其他收藏家签约会影响这条线的进度，还可能损失名声。

开局资助会把手头资金设为 **5,000 金币**，你的自动补钱随后会生效。[DOS 版实玩](https://www.bilibili.com/video/BV1FU4y1U7uu/)

## 2. 买藏宝图，找到金质奖章

1. 手头准备**超过 10,000 金币**。去欧洲以外的港口，先试**马德拉韦（Madeira）酒馆**。
2. 有人卖一张藏宝图，开价 **2,000 金币**。可以直接买，也可以第一次选不买，等他降到 **1,000 金币**再买。
3. 打开物品里的藏宝图，找红叉所示的海岸。开船到附近，从海上选**登陆**，在目标地带搜索，拿到**金质奖章**。部分攻略把这段写成「黄金假面」，你这版 DOS 酒馆对白叫「金质奖章」。
4. 拿到奖章后，先去普通港口的**码头办事处**。凯麦隆会先要看奖章，再提议一起去找**黄金国埃尔多拉多**。如果你已经到了里斯本，先去里斯本码头。如果那里只有普通对白，可以换到**波尔多码头**试一下。听完找黄金国的提议，再进**里斯本法雷尔公爵宅**接约翰的委托。

藏宝图的红叉就是这一档要找的位置，看到图再决定往哪儿开。[实玩攻略](https://www.ptt.cc/bbs/Koei/M.1618752726.A.50B.html)

## 3. 接约翰的委托，找圣人手杖

1. **冒险名声至少 10,000**，并且已经拿到奖章、谈过寻找黄金国。进**里斯本法雷尔公爵宅**，约翰会请你找**圣人手杖**，攻略也常叫**圣者之杖**。
2. 接下委托，去**码头**听提示，再去**亚丁（Aden）酒馆**打听。**霍尔木兹（Hormuz）酒馆**也在这段剧情的候选范围内。巴士拉也符合地点条件，但如果士兵提示「本港禁止意大利人登岸」，直接换港即可。这段剧情没有要求在巴士拉和士兵交涉。亚历山大港不在这段酒馆线索的范围内。
3. 酒馆会告诉你**哪座港口的占卜师**知道线索。**记下港名**，这条提示可能只说一次。常见候选有雅法、贝鲁特和亚历山大港，以你当次听到的为准。
4. 到指定港口的**占卜馆**。如果亚历山大港的士兵拦住你，就在同一个港口反复出港、靠港，让游戏时间走到**晚上 8 点（20:00）**。再靠港时士兵就撤了，可以进城。中文版 DOS 已实测成功。开了「白天画面」也可以用这招，认左侧的游戏时钟。占卜师会再报一个**港口的酒馆**。记下新港名，直接去那里的酒馆拿**手杖藏宝图**。反复问占卜师可能会改变他指的港口。
5. 按藏宝图的红叉登陆搜索，拿到手杖。带去**马沙华（Massawa，也叫马萨瓦、艾克斯港）酒馆**交给**约翰**。这一段结束会增加冒险名声。

手杖是复兴艾克斯王国的信物，约翰受当地国王所托。手杖找到了也要亲自交给约翰，才算走完这段。[实玩攻略](https://www.ptt.cc/bbs/Koei/M.1618752726.A.50B.html) · [DOS 版实玩](https://www.bilibili.com/video/BV1FU4y1U7uu/)

## 4. 从日本查到南美洲

1. **冒险名声至少 40,000**，并交完手杖。去普通港口的**码头**，等贸易商**阿兰**转达约翰的消息。游戏会提到北纬 36°、东经 135°一带的日本。
2. 到日本后，进**长崎（Nagasaki）码头**听第一段，再换到**堺港（Sakai）码头**听下一段。两座港可以对调，记得去不同的港口。
3. **恩斯特**会说，传说里的埃尔多拉多可能在**南美洲**，大概在西经 50°到 70°一带。听完再去新大陆。

## 5. 找到法雷尔祖父，回里斯本结局

1. 到**南美北岸**一带的港口，先试**卡宴（Cayenne，游戏也写开云）**，再试**伯南布哥（Pernambuco）**。先去**码头**，也可以进**酒馆、旅馆或交易所**试触发。如果一直只有普通对白，换一座当地港口。
2. 遇到**法布利斯·法雷尔**。他是约翰的祖父，也是早年发现黄金国的航海家。听完他的经历，皮耶德会决定把他送回家。
3. 把法布利斯带到**里斯本法雷尔公爵宅**，触发皮耶德的个人结局。

最后的交差地点是**法雷尔公爵宅**。听完法布利斯的对白就可以往回走。[DOS 版实玩](https://www.bilibili.com/video/BV1FU4y1U7uu/)

## 卡住时对照

- **热那亚码头没剧情**。先去酒馆听凯麦隆说公爵夫人愿意资助你。
- **拿了奖章，进公爵宅却没触发剧情**。先去**码头办事处**，听凯麦隆提出寻找黄金国。即使冒险声望已经满了，这段对白也要先触发。
- **占卜师报了个陌生港名**。先记下全名，瞬移工具可以搜简体中文、部分港名或英文。亚力山卓就是亚历山大港。
- **手里有藏宝图但不会走**。先看红叉在哪片海岸。港口瞬移可以缩短到附近港口的路，最后要从码头正常出港、到红叉附近登陆搜索。
