# 阿兰·维斯主线导航

从「航海修改器」启动修改版，新建阿兰或继续他的存档。金钱、声望和航海补给可按需开启。下面按游戏里发生的事件找下一站，进门、航行和选项由玩家操作。

| 你刚做到哪里 | 接下来去哪里 |
| --- | --- |
| 新开局 | 在**伊斯坦堡**进造船厂听萨利姆说沉船的事。去酒馆、码头、银行筹款，这三处顺序随意。回造船厂领船，去酒馆招普通船员，再从码头出航，至少过一个海上午夜。 |
| 拿到船并完成首次出航 | 回伊斯坦堡，身上带至少 **20,000 金币**，在酒馆、码头、银行、造船厂依次还四笔债。码头还完后，彼得借钱可以答应或拒绝。 |
| 还完四笔债 | 通过伊斯坦堡王宫的普通委托取得第一个爵位。取得爵位后，进**旅馆和市场**听完两处反应，再进**王宫选择觐见**。 |
| 苏丹第一次交代扩张任务 | 身上带 **100 金块（100 万金币）**，进伊斯坦堡银行登记这段剧情。出航过一个海上午夜再回来，去酒馆见约翰，再去码头换帆。出海后让卡特琳娜舰队接触你，这段交战会由剧情结束。 |
| 卡特琳娜放行 | 累计 **6 趟各达到航行第 5 天的航程**。每到第 5 天后靠港，再次出航才算新一趟。遇到卡特琳娜的那一趟若之后到了第 5 天也算。完成后去**伊斯坦堡酒馆 → 巴斯拉酒馆 → 伊斯坦堡酒馆**。 |
| 已在巴斯拉见到萨法，并回去告诉酒馆老板娘 | 保持奥斯曼国籍，通过市场或造船厂投资，使**奥斯曼控制至少 30 座港口**。可在王宫查看势力报告。达标后进**伊斯坦堡以外任一普通港口的码头**，再回**伊斯坦堡银行**接拉迪诺，送他到**威尼斯银行**。 |
| 威尼斯银行请你追讨彼得的借款 | **拒绝**可直接进入下一段。若**接受**，走**威尼斯码头 → 里斯本约翰家 → 里斯本码头 → 堺港酒馆 → 威尼斯银行**，回银行时带至少 **40 金块**。如果先到了长崎，先去长崎酒馆听线索再出港。 |
| 拒绝追债或已交账 | 回**伊斯坦堡王宫选择觐见**领取奖励。50 港只影响传话，觐见可以直接推进。 |
| 领完第二次王宫奖励 | 保持奥斯曼国籍，商业声望达到 **40,000**。把这个游戏先进**伊斯坦堡以外的普通港口码头**，再进**另一座由奥斯曼控制的港口酒馆**，酒馆这一步避开伊斯坦堡和巴斯拉。然后去**巴斯拉酒馆**见萨法和鲁斯特姆。 |
| 萨法和鲁斯特姆决定跟你回去 | **伊斯坦堡酒馆 → 威尼斯银行**。银行第一次报出的价格是当前金块加 500，最高 10,000 金块。攒到报价，再回银行答应交易。最后回**伊斯坦堡酒馆**触发结局。 |

自动补金币的下限是 **1,000 万金币**，能覆盖还债和 100 金块门槛。它相当于 **1,000 金块**，所以最后买房要以威尼斯银行实际报出的价格为准。奥斯曼控制港口数和爵位是独立的剧情条件。
