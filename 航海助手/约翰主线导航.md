# 约翰·法雷尔主线导航

从「航海修改器」启动修改版，读取第 1 槽。你已经完成里斯本的开场和偷渡客上船，存档停在海上。**现在可以靠港，进港口办事处一次，再去马赛或波尔多的酒馆。**

声望已经达到所有主线门槛。到站后仍要进指定建筑、听完对白，章节才会推进。要赶路可以用「港口瞬移」，遇到明确写着「在海上过夜」的步骤，就实际出港航行。

## 1. 失踪的王子与公爵受审

1. 靠港后进一次**港口办事处**。这一步可能没有特殊对白。
2. 去**马赛**或**波尔多**的**酒馆**，听王子失踪的消息。里斯本、塞维利亚和伊斯坦堡的酒馆不会触发这一段。
3. 进**造船厂**触发对峙和单挑。旅馆线索可以略过。
4. 再进**港口办事处**，听多明哥解释身份。
5. 回**里斯本**，依次进**法雷尔家 → 王宫 → 法雷尔家 → 港口办事处**。
6. 出港，在**海上过一次午夜**。

## 2. 卡特琳娜、露西亚与巴士拉

1. 进一栋普通建筑，再进**酒馆**，听说卡特琳娜在找你。
2. 进酒馆或其他普通建筑，直到卡特琳娜现身。没碰上可以先在街上走一会儿再进。同一时刻反复进门可能一直得到同样结果。
3. 进**港口办事处**，出海过一次午夜。再做一轮**酒馆线索 → 卡特琳娜现身 → 港口办事处 → 出海过夜**。
4. 第三次去**港口办事处**，随后出海迎战卡特琳娜的船队。
5. 海战后先去**里斯本以外的酒馆**，再进**里斯本酒馆 → 巴士拉酒馆 → 伊斯坦堡旅馆**。最后一站要进旅馆找阿兰。

## 3. 马萨瓦与波塞冬之杖

1. 出港后连续航行到**第 5 个航行日**，再靠港进一栋普通建筑，让阿兰给出马萨瓦线索。
2. 去**马萨瓦**，依次进**清真寺 → 镇西南的特殊建筑 → 任一普通建筑**。
3. 回**里斯本法雷尔家**，请彼得找权杖。
4. 回**马萨瓦特殊建筑**启动等待。等到**下个月 11 日或之后**，再进去两次，听完奥斯曼舰队来袭的消息。
5. 进**马萨瓦港口办事处**，听完卡特琳娜的对白，再出海打**两场**当地追击你的奥斯曼船队。
6. 回马萨瓦进一栋普通建筑让彼得交杖，然后进**特殊建筑 → 港口办事处**。

## 4. 送恩里科去日本

1. 进里斯本以外的普通港口**酒馆**，等恩里科提出去日本。马萨瓦酒馆可以作为第一站。
2. 去**长崎港口办事处**，送恩里科离队。

## 5. 新亚特兰蒂斯与结局

1. 先进一栋普通建筑，再去**里斯本公会**读信。
2. 去**堺港的特殊建筑**见恩里科。
3. 去加勒比海或附近的剧情港口。可选**哈瓦那（Havana）**。进交易所、商店等普通建筑，直到看到有人被追进酒馆。每次没触发，先走一会儿让游戏时间变化。
4. 进**酒馆**找露西亚，随后进**港口办事处**听行动计划。
5. **过一个日历日**，再进港口办事处出发。先接触剧情中的西班牙舰队，完成与埃塞基耶尔的交涉，再迎战马丁内斯的海盗舰队。
6. 胜利后回**里斯本法雷尔家**，触发约翰的主线结局。
