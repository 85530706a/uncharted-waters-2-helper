# 奥托主线导航

中文版 DOS 路线。奥托从**伦敦**出发，主要看**海盗声望**。每次收到新命令后先把港内对白听完，再出海找剧情舰队。

## 1. 伦敦领命，去塞维利亚夺船

1. 进**伦敦王宫**见亨利国王，领下对付西班牙舰队的任务。
2. 去**造船厂**领船，再去**码头办事处**见马休。按他的提示去**酒馆**见面，走完这段单挑。
3. 从伦敦出海后，先在**海上让游戏过一天**，等马休的船上对白播完，再去**塞维利亚（游戏对白也写赛维尔）**。如果已经瞬移到塞维利亚却进酒馆没反应，可以从当地码头出海等这段对白，再靠港。PC 版实玩提示，中间多次靠港可能错过夺船。
4. 先去**塞维利亚酒馆**，听马休提出夺船，再去**码头**拿西班牙大帆船。
5. 出海后留在塞维利亚近海等过**午夜**，听船上的对白。再回塞维利亚进设施，听马休说有人跟踪。再次出港后留在近海，等天亮触发西班牙舰队来袭。

[PC 版实玩路线](https://gamefaqs.gamespot.com/pc/564431-new-horizons/faqs/82274/new-horizons-storylines-guide)

## 2. 卡特琳娜和黄金船的插曲

- **海盗声望 5,000** 后，可以先去**里斯本（Lisbon）**。在同一个港口依次试**码头、酒馆、旅馆**，听到幽灵传闻后再进**交易所**见卡特琳娜。她会约你约两小时后到当地酒馆。这次见面可以错过，后面的王命仍可推进。
- **海盗声望约 15,000 至 20,000** 时，去**伦敦酒馆**可以碰到皮耶德的西班牙黄金船情报。这段可选。修改器默认把海盗声望补到 50,000，想看这段可以新开档时调低这一栏。

## 3. 南特、圣多明哥和亚马逊河口

> **海盗声望已达 30,000，码头仍未传达召见？** 如果手上还有未完成的升爵王命（例如寻找古代神雕像），可以先完成并回王宫交差，再去码头办事处。听到「亨利八世正要召见您，请您马上回伦敦去」，就可以回伦敦王宫领讨伐舰队的命令。这个办法在中文版 DOS 中有成功记录，是否每局都需要先交王命尚未确认。

1. **海盗声望达到 30,000** 后，可以先去**里斯本（Lisbon）码头办事处**听消息。收到亨利八世召见后，回**伦敦（London）王宫**领新命令，再去**伦敦公会**听西班牙舰队的情报。
2. 去**南特（Nantes）外海**，与剧情中的西班牙舰队交战。战后得知他们去了新大陆。
3. 到新大陆后，先在**开云（卡宴，Cayenne）**靠岸，进**码头办事处**。如果只有普通对白，再去**交易所**。听到西班牙舰队去了**圣多明哥（圣多明尼各，Santo Domingo）**后，再去圣多明哥外海与舰队开战。
4. 打完圣多明哥外海的海战，从**开云（卡宴，Cayenne）**出港，沿南美海岸往东南航行到**亚马逊河口外海**。向当地的西班牙舰队发起交战，等**卡特琳娜**现身劝你放过艾泽格。把对白按到**奥托下令「马休，撤！」**，回到海上后再去欧洲的**波尔多（Bordeaux）**。

[PC 版实玩路线](https://gamefaqs.gamespot.com/pc/564431-new-horizons/faqs/82274/new-horizons-storylines-guide)

## 4. 波尔多外海决战，回伦敦结局

> 如果波尔多码头只有普通对白，先确认上一段有没有听到奥托下令「马休，撤！」。这段还没播完时，回亚马逊河口找西班牙舰队触发海上剧情。

1. 回欧洲后直接去法国的**波尔多（Bordeaux）**。先进**波尔多码头办事处**听艾泽格已回国的消息，再去**波尔多酒馆**见他。如果码头对白已触发、酒馆仍只有普通对白，可以试附近的**南特（Nantes）酒馆**。
2. **接受一个月后在波尔多外海决战**。如果拒绝了，中文版攻略的补救路线是先回**伦敦王宫**，再去**塞维利亚司令部**重新接约。
3. 接近约定日时，从波尔多码头出海，在**波尔多外海**等到游戏提示**「终于到了约战日期」**。看到提示后，继续在附近海面寻找艾泽格的舰队，找到后发起交战并打赢。
4. 回**伦敦王宫**见国王，触发奥托的主线结局。
