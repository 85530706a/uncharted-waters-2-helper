# 《大航海时代2》中文版 DOS 航海助手

| 入口 | 用法 |
| --- | --- |
| 启动游戏副本.app | 原版繁体 DOS 游戏。首次启动从空存档开始，原版进度单独保存在隐藏目录 `.原版游戏`。 |
| 航海修改器.app | 勾选所需功能，点「启动修改版」。沿用「游戏副本」里的进度和简体对白。 |
| 港口瞬移.app | 也可以从修改器窗口里的「港口瞬移」打开。游戏中瞬移需要在启动时启用对应开关。游戏关闭时可以选择修改版的存档槽。 |

修改器每次打开时，金钱预填 600,000,000，商业、海盗、冒险声望各预填 50,000，其余功能开关默认关闭。切换补丁需要保存、退出游戏，然后从修改器重新启动。已经写入存档的金币、声望和地图会随存档保留。

- 航海补给停扣日常粮水，并在有余舱时自动补给淡水、食物、修船资材和炮弹。
- 「船长单挑无敌」和「船长单挑一击必杀」作用于人物决斗，分别让主角受到的伤害归零、命中时一击取胜。
- 「舰炮一击击沉」让己方舰炮命中时清零敌舰耐久。「接舷肉搏一击必杀」让己方接舷时清零目标船的船员。
- 金钱上限为 600,000,000，商业、海盗、冒险声望的上限各为 50,000。输入的是自动补回的最低值，留空时按游戏规则变化。
- 「全开村落及发现物」会解锁本局随机分配的普通村落发现物，包括珍兽、遗迹等。新解锁的发现物可留给王宫交差，已经报告过的发现物保留原状态。王命按原版流程，先到码头办事处听国王召见，再去王宫接任务。完成后回王宫交差。
- 如果想体验剧情安排的战斗或败北，启动时可以关闭相应的战斗开关。
- 「整备战斗舰队」会在启动前写入指定存档槽。默认整备 10 艘混合式快船，每船 150 名水手和 40 门炮。可填写船数和每船水手数，已有舰船多于所填数量时会全部保留并整备。空缺船长由随机招募的航海士担任，船长能力调到 100，船长和舰队里其他尚未登记的成员都会加入游戏的人物名单，并开启全舰队海战保护、无限弹药、炮击及接舷一击必杀。

## 主线目的地导航

勾选「主线目的地导航」后启动修改版。进游戏后可以回到修改器点「主线目的地…」，查看当前角色的剧情候选港口，选中港口可瞬移，到达后进对应设施。对白指定的临时线索仍以游戏里听到的为准。

手上已有藏宝图时，在港内街道或海上点「主线目的地…」，选择「直达藏宝点」，即可把船移到红叉旁的水面。对话或游戏菜单打开时，先退回街道或海面。到达后选「登陆」搜索，继续按游戏内的正常条件触发剧情。

游戏关着时也可以点「主线目的地…」，选存档和目的地。工具会在写入前备份存档，之后读取该槽即可。世界地图的压缩格式参考 [LSReader](https://github.com/yinchuan/LSReader)。

## 从源码构建

需要 macOS、Swift 命令行工具、Python 3.9 或更新版本，以及支持本地 `mcp_server` 的 DOSBox-X。当前环境使用 Homebrew 安装的 DOSBox-X 2026.10.01。把支持版本的原版繁体中文 DOS 游戏文件放在本目录的 `.原版资源` 下，并确认 `MAIN.EXE`、`KOUKAI2.COM` 与其余数据文件处于同一层。

```sh
chmod +x build_apps.sh launch_game.sh launch_gui.sh
./build_apps.sh
```

如已有本地的「游戏副本」，修改器会沿用它。初次创建修改版目录时，从本地原版资源复制。仓库的忽略规则排除本地游戏、存档、生成的 App 和手机移植包。

## 修改金币和声望

在终端进入本目录。列出游戏副本的存档槽和当前数值。

```sh
python3 sea2.py --save 游戏副本/KOUKAI2.DAT inspect
```

退出游戏后，以下命令将第 1 槽的金币设为 1,000,000、冒险声望设为 8,000，写出新的存档文件。省略的数值会保留原样。声望类别分别是 `--trade`（商业）、`--piracy`（海盗）、`--adventure`（冒险）。

```sh
python3 sea2.py --save 游戏副本/KOUKAI2.DAT edit 1 \
  --gold 1000000 --adventure 8000 --output 游戏副本/KOUKAI2-edited.DAT
```

要在游戏里读取修改后的存档，先把「游戏副本」里的 `KOUKAI2.DAT` 改名备份，再把输出文件改名为 `KOUKAI2.DAT`。启动器从「航海助手」内部的 `.原版资源` 读取补丁所需的原版文件。

## 手动选择锁定数值（可选）

这个命令用原版规则打开「游戏副本」里的进度，并提供终端调试命令。进入本目录后运行：

```sh
./launch_game.sh --live
```

进入游戏或读档后，切回终端并输入 `status` 查看当前数值。输入下面这条命令锁定金币和冒险声望。也可以单独锁定某一项。

```text
lock gold=10000000 adventure=8000
```

换角色、回到主菜单或读另一档之前，输入 `unlock` 解除旧锁定。数值写入后，解锁会让它重新按游戏规则变化。等存档完成再输入 `quit` 关闭游戏副本。三类声望上限是 50,000，剧情需要不同门槛时可以调整锁定值。

## 查看当前剧情章节

约翰第 1 槽的手动通关路线见[约翰主线导航](约翰主线导航.md)。

```sh
python3 sea2.py --save 游戏副本/KOUKAI2.DAT story 1
```

输出包含当前角色、港口编号、剧情章节和候选事件入口。是否触发还取决于对白选择、时段、声望等条件。

存档布局参考了[英文 DOS 版研究](https://github.com/JohanLi/uncharted-waters-2-research/tree/f6b5691/save-editor)和[中文版地址记录](https://www.xycq.org.cn/forum/thread-111651-1-1.html)。中文版的槽位长度和主角识别依据来自本地存档，修改后的金币和冒险声望已在里斯本实机读档核对。
