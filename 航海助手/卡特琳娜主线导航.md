# 卡特琳娜·艾兰茨主线攻略

适用于《大航海时代 II》DOS 中文版。开场她还是西班牙海军中尉，所以 NPC 会叫她「艾兰茨中尉」。桑多中尉是来找她的同僚。以下按剧情发生顺序排列，声望看人物页的**海贼名声**。

## 1. 塞维利亚开场

1. **海军司令部**。从城堡门口沿城镇北边往右走，进地图**右上角那扇门**。和艾泽格司令谈话，得知哥哥和未婚夫的船失踪。第一次谈完可以再进一次司令部，看看有没有交付佩剑的对白。
2. **酒馆**。见桑多，听到水手传言说葡萄牙法雷尔家的舰队与事故有关。
3. **回司令部**。卡特琳娜请求调军舰调查，司令拒绝。
4. **再去酒馆，然后去码头**。与桑多谈完离开海军的事，去码头夺船出海。出海后让游戏过一天，听完桑多的对话，开场结束。

[开场攻略](https://gcgx.games/dkj2/chart/catalina.html) · [DOS 版实玩流程](https://www.bilibili.com/video/BV1U1mXBEE4D/)

## 2. 西班牙舰队追捕，纪德加入

开场后，打赢一支普通舰队取得海贼名声。靠港，听到西班牙无敌舰队出动的消息。再出港迎战剧情舰队，要经历**两次交战**。这两场可以撤退，剧情仍可继续。之后安德鲁·纪德会加入。

[实玩攻略](https://www.ptt.cc/bbs/Koei/M.1618752726.A.50B.html)

## 3. 第一次追到约翰

- **海贼名声 1,500**。去塞维利亚以外的港口，进城听说约翰已经出海。
- **海贼名声 2,000**。到**塞维利亚和里斯本以外**的港口，进酒馆听新消息。出港，让海上时间过**超过一天**再靠港。先进**酒馆、旅馆或交易所**这类普通设施，触发「他们跑进造船厂了」。这一步直接进造船厂、码头或王宫不会触发提示。
- 听到「他们跑进造船厂了」后，留在**你听到这句提示的港口**，直接进**当地的造船厂**。遇见约翰后，艾泽格会赶到，打断追捕。

[实玩攻略](https://www.ptt.cc/bbs/Koei/M.1618752726.A.50B.html)

## 4. 佩罗提供线索，约翰又跑了

1. 第一次遇见约翰后，先出海连续航行 **3 天**再靠港。**海贼名声 8,000**后，进一家**酒馆以外**的设施，等纪德提起海盗佩罗，然后去酒馆找佩罗，记下他报的**港口名**。漏看可以去**里斯本法雷尔公爵宅**再打听。
2. 到佩罗说的港口，按**酒馆 → 另一家设施 → 酒馆**走一遍。
3. 接着反复进出**旅馆、酒馆等普通设施**。游戏会随机推进搜人剧情，而且推进前后可能都显示「好像不在这里」。每进出几次普通设施，就去**交易所**试一次。触发时会听见有人喊救命，找到被绑的桑多；随后去**码头**打听约翰的船。
4. 瓦伦西亚码头确认约翰已经出港后，换到另一个有酒馆的普通港口，例如**马赛**。进**马赛酒馆**找佩罗。他说要先把**路琪亚**带到休达。

[实玩攻略](https://www.ptt.cc/bbs/Old-Games/M.1618753256.A.28D.html)

## 5. 路琪亚、休达与黑海海战

1. **里斯本酒馆**找路琪亚，约好 **2 小时后去旅馆**会合。接到她后出港。
2. **休达旅馆**安置路琪亚，然后去**休达酒馆**找佩罗。他说约翰在亚力山卓，也就是港口列表里的**亚历山大港**。
3. 在**亚历山大港**进入城内设施，遇见奥托。他会告诉你中了佩罗的计，佩罗的船去了**黑海**。
4. 从**伊斯坦堡海峡**穿过去，在黑海找**佩罗本人的舰队**。这场**必须获胜**。打完先靠一次港。

## 6. 马沙华洗清约翰的嫌疑

1. **海贼名声 15,000**，并且已经击败佩罗、靠过港。再出港击败任意一支舰队，从俘虏口中得知约翰在**马沙华**，也叫马萨瓦。
2. 到马沙华，进城内设施听当地人谈约翰，再去**码头**见约翰。离开码头后再进一家设施，触发决定帮他抗击奥斯曼舰队的对话。
3. 出海和一支**奥斯曼舰队**交战。这场可以撤退。
4. 回**马沙华王宫**。听完恩里克和皮耶德的证词，卡特琳娜放下对约翰的误会。

[实玩攻略](https://www.ptt.cc/bbs/Old-Games/M.1618753256.A.28D.html)

## 7. 里斯本得知真凶

1. 上一段结束后，把海贼名声准备到 **30,000**，再连续航海**至少 5 天**后靠港。收到阿兰在旅馆等你的消息，就进**当前港口的旅馆**见他。
2. 阿兰让你去**里斯本法雷尔公爵宅**找皮耶德。在那里见到皮耶德和约翰的祖父，知道马丁内斯侯爵才是幕后真凶。
3. 离开里斯本，西班牙舰队会再次追捕。下一站去**南美洲**。

## 8. 南美会合与亚马逊河决战

1. 去**伯南布哥（Pernambuco）**靠港。中文版 DOS 脚本的触发港口范围排除了卡宴。到了伯南布哥，反复进出**旅馆或交易所**，等到同伴说**有人往酒馆跑了**。
2. 去酒馆，遇见约翰、路琪亚和死神鲁道夫。触发单挑，**输赢都能继续**。打完去**码头**与约翰谈联手。
3. 按对话安排出港。遇到艾泽格的西班牙舰队时，选**投降或交涉**，让约翰向司令解释阴谋。司令会答应合作。
4. 沿**亚马逊河向内陆航行**，找到马丁内斯一方的**剧情海盗舰队**。击败一支后进入卡特琳娜的结局。此阶段不要主动攻击约翰或艾泽格的舰队，DOS 台词明确提示那会让你错过结局。

## 卡住时对照

- **满声望仍然没剧情**。按上面顺序回头补上一个事件，尤其是指定建筑里的对话。名声达标后，仍要满足靠港、进设施或海上时间条件。
- **等 1 天或 5 天时**。用正常出港航行，让游戏日历确实走够，再靠港。连续航海计时从出港起算。
- **被要求去「司令部」**。塞维利亚地图右上角的门，与城堡入口在同一排。
- **该赢的战斗**。前期取声望的普通海战、黑海打佩罗、马沙华前打出俘虏线索的那场普通海战，以及亚马逊决战。
