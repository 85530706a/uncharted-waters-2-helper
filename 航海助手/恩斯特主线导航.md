# 恩斯特主线导航

中文版 DOS 路线。恩斯特是从**阿姆斯特丹**出发的绘图师。主线要送**劳拉**回家，主要看**冒险声望**。绘完世界地图可以作为支线目标，主线结局不用把地图画满。

## 1. 阿姆斯特丹领船，认识劳拉

1. 进**阿姆斯特丹的梅尔卡特家**，听开场委托，领船和经费。
2. 出海探索，再回**梅尔卡特家**报告地图。PC 版实玩记录，这一步至少要探索一格并报告。做完报告时，**冒险声望至少 1,000**。
3. 去**阿姆斯特丹码头办事处**，遇见想搭船找家乡的**劳拉**，答应带她同行。

[PC 版实玩路线](https://gamefaqs.gamespot.com/pc/564431-new-horizons/faqs/82274/new-horizons-storylines-guide)

## 2. 逐段听码头对白，找到日本的线索

1. 冒险声望达到 **5,000**、**20,000** 后，到普通港口进**码头办事处**，依次触发劳拉的对白。可以去**索法拉（Sofala）**。中文版 DOS 实测，在索法拉反复进出码头办事处，每次把对白读完，约两三次后就听到了去日本的线索。
2. 声望达到 **40,000** 后，继续进出码头，直到**斯塔特提到黄金国日本**。即使修改器把声望补到 50,000，也先把码头对白按顺序走完。
3. 到东亚港口，例如**泉州（Zeiton）**、**澳门（Macao）**或**河内（Hanoi）**，进**码头**。听到日本还在东北方之后，再去日本。

[中文版实玩攻略](https://www.ptt.cc/bbs/Old-Games/M.1618753256.A.28D.html) · [PC 版实玩路线](https://gamefaqs.gamespot.com/pc/564431-new-horizons/faqs/82274/new-horizons-storylines-guide)

## 3. 日本问黄河，长安看结局

1. 到**长崎（Nagasaki）**或**堺港（Sakai）**，先进**码头**。
2. 再进城里另一处设施，听恩斯特说当地人长得像劳拉。劳拉会提到家乡附近的水是黄色的。
3. 回**码头**继续问，直到听到明确的**黄河**线索。如果只说没听过黄色的海，出门再进码头。
4. **从黄河口沿河往内陆走，找到长安（Changan）**。进长安后去城西的**王宫**，触发主线结局。进长安前可以另存一档，方便回去继续绘图。

[PC 版实玩路线](https://gamefaqs.gamespot.com/pc/564431-new-horizons/faqs/82274/new-horizons-storylines-guide)

## 绘图支线

绘图报告交给**阿姆斯特丹的梅尔卡特**。如果想完成他的地图委托，先完成绘图并回去报告，再进长安。即使世界地图已经全开，主线也要走完码头、日本和黄河的对白。
