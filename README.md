# 大航海时代 II 航海助手

适用于 macOS 和繁体中文版 DOS 游戏的启动器与可选修改工具。

- **启动游戏副本**使用原版游戏文件和独立存档。
- **航海修改器**按需开启航行、战斗、金钱、声望、地图与港口瞬移等功能。
- **港口瞬移**可从修改器窗口打开，也可单独使用。

项目源码需要搭配本地游戏文件和支持调试接口的 DOSBox-X。构建步骤、存档位置和开关说明见[使用说明](航海助手/使用说明.md)。

## 简体中文补丁

补丁包含简体字库、通用对白修正及六位主角的剧情对白润色。使用 Python 3.9 或更新版本，在仓库根目录运行下列命令，将兼容的繁体中文版 DOS 游戏复制到一个新目录并应用补丁。

```sh
python3 安装简体补丁.py 航海助手/.原版资源 航海助手/游戏副本
```

如果「游戏副本」已经存在，请把命令的最后一个参数改成尚不存在的目录。补丁保留原版文件，生成的简体副本从空存档开始。修改器默认使用「游戏副本」，原版启动器仍使用繁体资源。
