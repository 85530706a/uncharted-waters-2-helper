# 大航海时代 II 航海助手

在 macOS 上玩繁体中文版 DOS《大航海时代 II》的启动器、修改器和攻略合集。用 DOSBox-X 运行你自己的游戏文件，原版进度和修改版进度分开保存，互不影响。

> 本仓库不含任何游戏文件，需要自备繁体中文版 DOS 游戏。

## 功能

**三个 macOS App**

| App | 作用 |
| --- | --- |
| 启动游戏副本 | 原汁原味的繁体原版，存档单独保存。 |
| 航海修改器 | 勾选需要的功能，启动修改版游戏，使用简体对白。 |
| 港口瞬移 | 选一个港口，船队直接到港。也能从修改器窗口打开。 |

**修改器开关**（全部默认关闭，按需勾选）

- 航行：补给锁定、防海上灾害、加快航行、白天画面与建筑全天营业、委任航行常用港口置顶
- 战斗：海战无敌、舰炮一击击沉、接舷肉搏一击必杀、船长单挑无敌、船长单挑一击必杀
- 资源：金钱与商业、海盗、冒险声望自动补到指定下限
- 地图：全开地图及已知港口、全开村落及发现物
- 剧情：主线目的地导航，列出当前章节的候选港口和已持有的藏宝点，一键瞬移
- 整备战斗舰队：启动前把指定存档槽补满到最多 10 艘船，配好船长和水手，并登记到游戏的人物名单
- 片头可按回车直接跳过

**简体中文补丁**：简体字库、通用对白修正，以及六位主角的剧情对白润色。

**六位主角的主线攻略**：[约翰](航海助手/约翰主线导航.md)、[卡特琳娜](航海助手/卡特琳娜主线导航.md)、[奥托](航海助手/奥托主线导航.md)、[恩斯特](航海助手/恩斯特主线导航.md)、[皮耶德](航海助手/皮耶德主线导航.md)、[阿兰](航海助手/阿兰主线导航.md)。

## 需要准备

- macOS，以及 Xcode 命令行工具（提供 `swiftc`）
- Python 3.9 或更新版本
- Homebrew 安装的 [DOSBox-X](https://dosbox-x.com/)，需支持本地调试接口 `mcp_server`
- 繁体中文版 DOS《大航海时代 II》的游戏文件，`MAIN.EXE` 的版本须与工具支持的一致（工具会校验，不匹配时直接提示，不会改坏文件）

## 快速开始

1. 把游戏文件放进 `航海助手/.原版资源/`，`MAIN.EXE`、`KOUKAI2.COM` 和其余数据文件放在同一层。
2. 生成简体版游戏副本（在仓库根目录运行）：

   ```sh
   python3 安装简体补丁.py 航海助手/.原版资源 航海助手/游戏副本
   ```

3. 生成三个 App：

   ```sh
   cd 航海助手
   ./build_apps.sh
   ```

4. 双击「航海修改器」，勾选功能后点「启动修改版」。

各开关的详细说明、存档位置和命令行工具见[使用说明](航海助手/使用说明.md)。

## 安全性

- 原版游戏文件只读，所有修改都写在单独的「游戏副本」里。
- 打补丁前用 SHA-256 校验原版程序，版本不符就停止。
- 改存档的命令行工具只写新文件，不覆盖原存档；修改器在启动前改存档时，会先在内存里完整生成并校验，再一次写入。

## 开发

```sh
cd 航海助手
python3 -m unittest discover -p 'test_*.py'
```

测试需要 `.原版资源` 里的原版游戏文件。

| 文件 | 内容 |
| --- | --- |
| `layout.py` | 存档和游戏内存的数据结构 |
| `sea2.py` | 存档读写、剧情章节解析 |
| `patches.py` | 生成修改版 `MAIN.EXE`、`OPEN.EXE` 和剧情文件 |
| `live.py` | 通过 DOSBox-X 调试接口锁定数值、自动补给、整备舰队 |
| `teleport.py`、`story_destinations.py` | 港口瞬移和主线目的地导航 |
| `app_launcher.swift`、`port_picker.swift` | macOS 界面 |
